Total build cost · 8 stations
$175 per station · not included: field supplies (superglue gel, paint pens) and Pi Connect remote access (about $0.50 per station per month)
$1,400
Tag specifications: AprilTag 36h11 family · 6mm printed size · read from 3280 × 2464 camera frames · attached to the top of the thorax with superglue gel · each bee keeps the same ID across all 8 stations.

Network: All 8 stations registered on UP IoT network (UPIoT) by MAC address · no credentials required · remote access via Pi Connect · each station uploads new detections to the shared Google Sheet every hour from 10am to 6pm.
